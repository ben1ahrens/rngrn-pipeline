# Caption data — GRN topology + non-identifiability

Every number below is traceable to `data/topology_stats.json` / `data/topology_runs.json`,
which are regenerated by `make_topology_figures.py` from the tracked run records listed in
`README.md`. Prose is the owner's; this file supplies the numbers and the caveats that must
travel with them.

---

## The finding, stated once, plainly

**Recovery identifies a dynamical equivalence class, not a topology.**

- **26 seeds across 3 targets produced 26 distinct Jacobian sign structures.** No two
  seeds agreed. (10/10 on D5, 8/8 on c2_P A, 8/8 on c2_P B, at the structural 5 %
  zero-tolerance.)
- **Sign recovery is at chance.** Pooled median `sign_match_frac` = **0.3333** over 26
  runs; uniform chance over {−, 0, +} = **0.3333**.
- **It is arguably below a trivial baseline.** The true sign vector for c2_P A / D5 is
  `[+,−,−,+,−,0,+,0,−]` — 4 minus, 3 plus, 2 zero. A constant "predict − everywhere"
  guess scores **4/9 = 0.4444**, *beating* the observed median. A label-shuffled null
  (each run's own 9 signs permuted, 200 000 draws, seed 20260818) means **0.3886**, also
  above the median.
- **The same models reproduce the phenotype.** Among runs that converged to a
  Turing-unstable solution, **19/20 pattern in rollout** (D5 4/4, c2_P A 7/8, c2_P B 8/8),
  and morphology is classified `labyrinth` matching the target in every patterning run.
- **And they get the wavelength right.** Among Turing-converged runs, median
  `kstar_rel_err` = **4.8 %** (D5), **3.1 %** (c2_P A), **6.5 %** (c2_P B); worst single
  run 9.8 %.

So: **wavelength and morphology are recovered; the network that produces them is not.**

True Jacobian sign vector, row-major:
- D5 and c2_P A (same system): `[+, −, −, +, −, 0, +, 0, −]`
- c2_P B: `[+, 0, −, +, −, 0, +, 0, −]`

True topology, all three targets: `double_inhibitor`,
`interaction_matrix = [[1,−1,−1],[1,0,0],[1,0,0]]` (row = target, col = regulator) —
gene 1 self-activates and is repressed by genes 2 and 3, each of which gene 1 activates.
**4 non-zero edges.** Every learned network is visibly denser (fig1–fig3).

### fig3_learned_vs_true_target{A,B}.png
Ground-truth network beside the worst / median / best learned network **ranked by the
6-permutation aligned score**, with the learned panels relabelled by that permutation.
Note that the pinned score does **not** follow the same order — target B seed 7 is "best"
on the 6-perm score (0.778) but has the group's *lowest* pinned score (0.222). The panel
labels name the ranking basis for exactly this reason; a caption must not describe these
as "best/worst recovery" without saying by which score.
Two further things a caption must say:
1. **The truth panel's edge widths are uniform and carry no information.** The generator's
   reaction is `dx_i/dt = b_i + V_i · Π_j g(x_j; K_i, n) − mu_i·x_i`
   (`scripts/gen_tg3.py:93`), in which `K` is indexed by the **target** gene and shared
   across all of that gene's regulators. The truth has no per-edge binding strength
   comparable to the model's `KA`/`KR`. Per-gene quantities map by role: V→α, b→β, mu→δ,
   D→D. Edge width is meaningful **only in the learned panels**.
2. **The 6-permutation score is an upper bound** (see the caveat section below).

### fig3b_sign_matrices_target{A,B}.png
The 3×3 Jacobian sign matrices — what `sign_match_frac` actually compares. Included
because the topology diagram draws `KA`/`KR` while the score is computed on `J`; they are
different objects and conflating them in a caption would be an error. Each learned panel
prints **both** the 6-perm upper bound and the pinned admissible score.

## Caveats that must not be dropped

**1. The two zero-tolerances disagree, and the looser one flatters the result.**
`sign_match_frac` and `scoring.permutation` use rtol **1e-9** (`validate.py:77`), which
treats any nonzero float as a real edge. `metric.repro_sign_vector` uses rtol **0.05**
(`metric.repro_sign_zero_rtol` in every run record). On this data they disagree: **c2_P A
seeds 1, 4 and 7 share one sign vector at 1e-9 but are three distinct structures at
0.05**, because entries as small as **2×10⁻⁴ of max|J|** are being counted as edges. Those
same three seeds are the group's top scorers (0.778 each) — so 1e-9 both *understates*
the diversity and *inflates* the top scores. Both conventions are reported everywhere;
neither is silently preferred. Prefer 0.05 for any claim about *structure*; use 1e-9 only
when comparing against previously reported `sign_match_frac` values.

**2. The 6-permutation search answers a weaker question.** All 26 runs are fully observed
(N = m = 3, `observed_idx=[0,1,2]`), so the gate pins every channel and the admissible
permutation set has exactly **1** element — the identity. `free_observed=True` enumerates
all 6 only by discarding that known correspondence; `align_permutation`'s docstring
requires such a score be reported as an upper bound. Quoting the 6-perm median alone
would raise the figure from 0.333 to ~0.67 and would be wrong.

**3. D5 and c2_P target A are the same system, not two.** `turing_labyrinth/sample_0000`
records `source_dataset='three_gene_qvar'`, `source_key='sample_0001'`; the two samples
have identical `jacobian`, `interaction_matrix`, `params_json` and `sim_seed`
(1072191045), differing only in grid (512 vs 96). **Independent targets in this figure
set: 2, not 3.** The seed counts remain independent within each run group.

**4. Nothing here is a controlled identifiability experiment.** These are seed replicates
of two existing run groups, re-scored post-hoc. They show that the objective as configured
does not pin the sign structure. They do **not** establish *why* — a deliberate
identifiability study (varying observation count, noise, or the objective's terms) has not
been run, and no claim about the cause should be made from these figures.

**5. What is NOT measured here.** No claim is made about (a) recovery of edge
*magnitudes*, (b) whether the learned equivalence class contains the truth,
(c) identifiability at N > 3, or (d) partially observed arms — every run here is fully
observed, which is the *easiest* case, and it already fails to identify the topology.

**6. Uncalibrated thresholds inherited from the pipeline.** `recovered_turing` uses
`strict_max_re_eig`; `rollout_patterned` and `morphology_match` come from
`eval/rollout.py` and the morphology bank `default_centroids`. This figure set neither
calibrates nor re-derives any of them; it reports them as the runs recorded them.
